# きき湯の神殿 — Vket 2026 Winter アース製薬ブース 体験モック

VRChat（Udon）で本実装するための、遊べるモック一式です。

## 中身

| ファイル | 内容 |
|---|---|
| `index.html` | 3Dモック本体。ブラウザで開くと、ストリート→入口→メインゲーム→FINE HEAT→ひみつの壁→キャンペーン→出口まで一周できます |
| `libs/three.min.js` | 描画ライブラリ（three.js r137）。同梱なのでオフラインでも動きます（フォントだけGoogle Fontsから読み込み、なければ代替フォント） |
| `bgm_*.mp3` | BGM 4曲（下の「BGM」参照） |
| `3d/booth_layout.glb` | ブースの配置データ（柱・ドーム・塔・浴槽・鏡枠・看板・装飾など約3,300パーツ）。Unity／Blenderに読み込んで、レイアウトの下敷きに使えます |
| `spec.json` | 座標・ゲームの数値・フロー・商品対応など、実装に必要なパラメータ |
| `images/` | モックのスクリーンショット（全景・鏡のゲーム画面・クリア時の自動撮影・FINE HEATの入浴ショット） |

## 動かし方

`index.html` を直接ダブルクリックでも動きますが、BGMが鳴らないブラウザがあります。その場合はこのフォルダでローカルサーバーを立てて開いてください。

```
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

操作：WASD 移動／ドラッグ 見回す／クリック ボタンを押す（VRではコントローラーのトリガー）／Shift 走る／V 視点切替／M メニュー（ワープ・BGM差し替え・企画メモ）

## 体験の流れ（一周 約4〜5分）

1. **視認**：通りから白×金の神殿、ガラスのドーム、空中の「きき湯」サイン、左右の看板塔、2階ギャラリーと小ドームの塔が見える
2. **ようこそ**：花のアーチ＋女神の吹き出し＋案内板（スタンプ①）
3. **メインお風呂ゲーム**（約90秒）
   - STARTの台をタッチ → お悩み診断（腰痛／肩こり／冷え性／肌荒れ）→ 遊んだ量 → おすすめのきき湯
   - 同じ色のバブルガンを持って、自分で鏡の前の光る円へ → STARTボタン
   - 鏡に自分がアップで映る（カメラ固定・少しだけパン）。30秒で疲れ岩を浄化。岩が増えると疲れ顔でうなだれる
   - スコアで炭酸水柱が3段階 → 両手を広げた笑顔で舞い上がる → 俯瞰アングルで自動撮影（スタンプ②）
4. **FINE HEAT 神経衰弱**（約60秒）：5枚の3Dカード → お悩み看板5問 → 最後の質問でおすすめ → ツブをバスタブに投げ入れる → 泡 → 自分でバスタブに入る → セルフタイマー撮影（スタンプ③）
5. **きき湯のひみつ**：奥の壁のポスター4枚＋ムービー枠。3つ見るとスタンプ④
6. **キャンペーン**：アンケート／ここから買えるよ／#Vketきき湯 フォトフレーム（スタンプ⑤）
7. **出口**：おみやげカード（スタンプ・今夜のおすすめ・撮った写真）

## VRChat（Udon）実装メモ

- **操作**：すべてワールド空間のパネル＋ボタン。レーザーでねらってトリガー。自動移動はしない
- **アップの鏡**：VRC Mirrorではなく、頭位置を狙うローカルカメラ→RenderTexture。自分だけが映るので同時プレイ可
- **バブルガン**：VRC_Pickup＋ParticleSystem、疲れ岩はParticle Collisionで判定。4色はマテリアル差し替え
- **疲れ岩**：頭ボーン基準のアンカー（肩・腰・手・頬）へ落下、3ヒットで破砕。体格差は頭の高さの比率で吸収
- **炭酸水柱**：スコア帯で3種。水柱だけはグローバル同期して周囲にも見せる
- **自動記念撮影**：ワールドから端末へ写真を自動保存できないため、撮影カメラの画像をボードに表示し、カウントダウン＋フレームでVRChatカメラ撮影を促す
- **BGM**：エリア別AudioSourceを距離でクロスフェード。クリアジングルは一時的に他を下げる

- ブースサイズ・ポリゴン・Udon規定は Vket 2026 Winter の入稿レギュレーションに合わせて調整
